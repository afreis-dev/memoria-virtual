# Memória Virtual

Implementação 6 da disciplina de Infraestrutura de Software (CESAR School): gerenciador de memória virtual em C, a partir do *Designing a Virtual Memory Manager* (*Operating System Concepts*, Silberschatz et al., 10ª edição, p. P-51), com memória física de 128 frames.

## Requisitos

- Linux, Unix ou macOS
- Compilador C com suporte a C11 e `make`

## Compilação

```sh
make
```

Gera o executável `vm` na raiz do projeto. Para remover os arquivos compilados:

```sh
make clean
```
